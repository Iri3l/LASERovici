# LASERovici

An online shop for custom **laser engraving** products.  
Built with **Next.js**, **TailwindCSS**, and **PayPal/Stripe integration**.

## 🚀 Tech Stack
- **Next.js** (App Router)  
- **TailwindCSS** for styling  
- **PayPal Checkout** (Apple Pay & Google Pay planned via Stripe)  
- SEO metadata, Open Graph, and Twitter Cards
